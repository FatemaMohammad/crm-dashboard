# Design Decisions

## Goal

The dashboard should provide users with a quick overview of the most important CRM information.

---

## Technology

- React
- TypeScript
- Tailwind CSS
- Vite

Reason:
Modern frontend stack with fast development, reusable components and type safety.

---

## UI Principles

- Clean layout
- Consistent spacing
- Reusable components
- Responsive design
- Accessible interface

---

## Dashboard Priority

1. KPI Overview
2. Customer Activity
3. Tasks
4. Project Progress
5. Quick Navigation

## Layout Structure

The application uses a fixed sidebar and a flexible content area. This layout is common in CRM systems because it provides consistent navigation while maximizing the available space for dashboard content.


# Logo & Branding

## Decision

The original placeholder logo was replaced with a custom icon based on the **Share2** icon from Lucide React.

## Why

Instead of using a simple letter "W", I chose an abstract icon that better represents the purpose of a CRM system.

The icon symbolizes:

- Connections between customers and teams
- Communication and collaboration
- Data flow between different parts of the business

This gives the application a more modern SaaS appearance while avoiding the use of an unofficial company logo. It also makes the dashboard feel more like a real product instead of a prototype.

## Design Principles

- Clean and minimal
- Easy to recognize
- Scalable as an SVG icon
- Consistent with the rest of the Lucide icon set
